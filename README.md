# Django Management System

A Django project containing four apps for managing different types of
organizations: School, Gym, Mess, and Hospital.

## Applications

### 1. School
- Student records
- Roll numbers, email addresses, courses, and contact details

### 2. Gym
- Gym member records
- Membership types, fees, and membership dates
- Trainer details and specializations

### 3. Mess
- Customer records
- Meal details, prices, and availability
- Customer subscriptions and plans

### 4. Hospital
- Doctor records and specializations
- Patient records
- Doctor appointments

## Technologies

- Python
- Django
- SQLite
- Django Admin

## Requirements

- Python 3
- pip
- Git
